# Phishing Website Analytics Dashboard

## Project Name

**Phishing Website Analytics Dashboard Using Python and Power BI**

## Project Description

The Phishing Website Analytics Dashboard is a data analytics project designed to analyze phishing and legitimate websites using Python and Power BI.

The project identifies suspicious website characteristics and presents important security insights through interactive visualizations.

## Objectives

* Analyze phishing website datasets.
* Identify common characteristics of phishing websites.
* Perform data cleaning and preprocessing using Python.
* Analyze URL and security-related features.
* Create interactive dashboards using Power BI.
* Provide useful insights for identifying potentially suspicious websites.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Power BI
* CSV Dataset
* Jupyter Notebook / VS Code

## Key Features

* Phishing vs. legitimate website analysis
* URL length analysis
* HTTPS/security indicator analysis
* Website risk analysis
* Interactive Power BI visualizations
* Data-driven security insights
